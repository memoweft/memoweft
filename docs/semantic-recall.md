# 调优分支：本人档案与分散查原话

此分支基于实验 C（#137）。E1 只在形成原则中要求保留具体内容、独立事实及变化起点，并使用现有 supersedes 合同；E2 保持 E1 的形成，增加下面的召回方式。它们是调优方案，尚未经留出集考试；不改变主库或 Portable 格式。

## 排序与预算

本机 multilingual-e5-small 就绪后，从当前账户的向量索引提名最多 32 条。通过现有权限、人物、历史和生命周期校验的候选按语义相似度排序，再按置信度和编号稳定打破平局。字面匹配补在语义结果后面，字面 `MIN_SCORE` 不再否决语义候选。正式记忆仍最多 5 条、600 字符。模型未加载、索引未补齐或推理失败时，保留原字面路径；结果应连同索引状态理解。

语义阈值默认 `0.75`，在实验考试前固定，不根据考题或考试结果调整。它比原有补充候选阈值宽松，可能增加误带；质量以独立实验报告为准。

涉及本人的问题会附一小段当前档案，最多 18 条／1800 字符。选择来自现有 attribute / naming 类型、有原话支持的本人陈述或明确归属的所有格语境，保留来源时间、原文与归属，不重新改写主体。没有新增按职业、收入、家庭等考点分类的词表；较短的身份条目优先，长条目可能没有空间。本人姓名及别名仍须来自当前可读的既有身份链，未知姓名、未经确认的名字片段、同名冲突及已撤回别名不能建立本人身份。第三方姓名问题不附本人档案。档案条目加入现有 selected_item_ids，使正式记忆依赖可以被追踪；count 包含这些条目，不再仅是原来的最多五条主召回。

原话最多 5 段／2600 字符，每段最多 420 字符。候选扫描同账户近期 256 个 spoken 来源，每个最多四段完整句窗口（长句用重叠原文片段，超长来源均匀选窗并保留末段）。问题本身加最多四个词组或中文片段分别评分，轮流选相关来源，抑制重复并限制每个来源最多两段；不生成问题、不添加领域别名或考题例子。编码器在每次请求内只编码一次来源窗口，不持久保存原话向量。原话仍带来源时间和节选标记，完整实际上下文长度由主记忆、档案与原话各自预算约束。

未形成正式条目的第一人称原话也可以参与退路；来源必须仍然可读、同账户、未删除并在有效期内。与被排除的正式条目共用的整段来源仍保守排除；不能借原话复活归档、静音、撤回、更正前值或遗忘内容。第三方及歧义人物过滤不由语义分数放行。没有新 World 写入、原话索引或持久文本副本。

语义模型不可用时保留原字面主路，原话退路不返回；本人档案不依赖编码器。它仍是只读、确定性、权限检查后的输出。原中文正文截断会另保留省略号，原来 600 字符预算实际可为 601 字符。三块合计约 5000 字符上限，预算不是无条件填满。

## 安装与配置

```powershell
cd py
uv sync --locked --extra dev --extra semantic
```

| 配置键                        | 默认值                                     | 含义                                   |
| ----------------------------- | ------------------------------------------ | -------------------------------------- |
| `MEMOWEFT_SEMANTIC_ENABLED`   | `1`                                        | `0`、`false`、`off` 关闭语义与原话退路 |
| `MEMOWEFT_SEMANTIC_THRESHOLD` | `0.75`                                     | 有限数，范围 0–1                       |
| `MEMOWEFT_SEMANTIC_CACHE_DIR` | 记忆库目录下 `cache/multilingual-e5-small` | 本机模型权重缓存                       |

`SemanticConfig.max_additions` 为兼容已有调用保留，不再限制语义优先结果；统一使用正式记忆与原话各自的输出上限。修改环境变量后重启桥。可选依赖缺失或模型失败时降级，不调用生成模型。

模型仍为固定版本 `intfloat/multilingual-e5-small@614241f622f53c4eeff9890bdc4f31cfecc418b3`，CPU 推理、384 维、最长 512 词元、E5 前缀与归一化保持不变。权重长度与 SHA-256 校验见 [model.py](../py/src/memoweft/semantic/model.py)。首次下载只获取权重，不向模型源发送记忆或问句。

`health.runtime.semantic_recall` 仍报告 `disabled`、`preparing`、`ready`、`unavailable` 和 `backfill_complete`。正式记忆向量继续使用同库附加表及原有事务内删除触发器，编码提交前重新检查内容与权限；来源改变或遗忘后不能发布旧向量。无 schema 迁移，Portable 不包含这些派生向量。

## 验证与限制

合成边界测试见 [test_semantic_primary_recall.py](../py/tests/test_semantic_primary_recall.py)、[test_semantic_recall.py](../py/tests/test_semantic_recall.py) 和 [test_named_owner_recall.py](../py/tests/test_named_owner_recall.py)。原有测试与断言保留，旧排序合同的失败与原则版既有提示词失败分别记录。

原话与档案扩大了上下文预算及本机推理成本；单用户已见数据调优不能证明留出集质量、日用质量、安装验收或可合并。来源候选池、窗口与向量输入截断、保守的整段排除都会造成遗漏。此分支不更新 WeftMate，宿主采用新增原话上下文前仍需独立集成与生命周期验收。
